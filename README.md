# Rufino Lab — web

Propuesta de web para **Rufino Lab** (alitas y boneless, Trujillo · IG [@rufino_lab](https://www.instagram.com/rufino_lab/)).

- `index.html` — la web lista (abrir en el navegador).
- `_src.html` — fuente; `index.html` se genera desde aquí con los símbolos SVG ya incrustados.
- `assets/` — fuentes e imágenes.
- `analisis.md` — notas del análisis del negocio.

Ganchos para probar: `?dry` (no abre WhatsApp, solo muestra el mensaje), `?nointro`, `?static`.

Pendiente de confirmar con el dueño: que el número tenga WhatsApp, horarios y zonas de delivery.
